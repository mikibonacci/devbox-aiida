# How-to guides

Short recipes for common tasks. They assume the [installation](../installation.md) is complete, that you run commands from the repository root, and that you have run `source scripts/init_hook.sh` in your terminal.

<div class="grid cards" markdown>

-   **Manage the services**

    Start, stop and inspect PostgreSQL and RabbitMQ, read their logs, change ports.

    [Services](services.md)

-   **Create and manage profiles**

    Create, inspect, delete or reset profiles and the daemon.

    [Profiles](profiles.md)

-   **Set up computers and codes**

    Register a computer and all its codes from YAML files.

    [Computers and codes](computers-and-codes.md)

-   **Install pseudopotentials**

    SSSP, PseudoDojo, or your own families.

    [Pseudopotentials](pseudopotentials.md)

-   **Use Jupyter notebooks**

    Run notebooks with the right environment and profile.

    [Jupyter](jupyter.md)

-   **Install additional plugins**

    Development versions of `aiida-yambo` and the Wannier90 workflows.

    [Plugins](plugins.md)

-   **Something is not working**

    Sockets, ports, stale files, daemon, broker and tab completion issues.

    [Troubleshooting](troubleshooting.md)

</div>
